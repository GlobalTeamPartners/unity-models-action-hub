## Architecture & Modules

The Action Hub is built as an ultra-fast, zero-dependency, static editorial command center inspired by `tentorium-sales-hub` with dark-gold & emerald luxury aesthetics (`#0B0E14`, `#121721`, `#C5A059`, `#10B981`):

1. **`index.html`** — Executive Command Center: key metrics, fast action bar, 6 core modules, live platform ecosystem directory, interactive USD/AED/RUB express calculator, and 90-day launch roadmap.
2. **`office.html`** — Representative Action Terminal: 3 role views (Moscow Global Plus Representative, Founder / HQ, International Country Reps) with interactive, browser-saved checklists (`localStorage`).
3. **`playbook.html`** — Top-Agency Global Playbook: benchmarks from IMG (`#WLYG`), EWG, DNA, Avant Moscow, Grace, Lumpen; 2025–2026 Schengen visa routing via Istanbul/Asia into Dubai; UAE compliance (Visitor Advertiser Permit & UAE Media Council per Federal Decree-Law No. 55 of 2023); neutral banking rails (UAE/KZ/GE/AM); consent-first AI Digital Twins (H&M × Uncut royalty model).
4. **`scripts.html`** — Outreach, PR & Objections: 6 one-click copy templates (Russian scouting with Zero-Upfront Charter, Moscow studio B2B, Dubai host agency pitch, brand lookbook packages, country rep recruitment, media press release) + 8 common objections handled.
5. **`markets.html`** — 14-Market Expansion Matrix: filterable & searchable intelligence table for Moscow, St. Petersburg, Dubai, Abu Dhabi, Istanbul, Shanghai/Guangzhou, Seoul, Tokyo, Bangkok, Almaty/Astana, Milan, Paris, London, and New York.
6. **`onepager.html`** — Print-Ready Executive Memorandum: clean A4 layout optimized for PDF generation (`window.print()`) in Russian and English.
7. **`calculator.html`** — Transparent Unit Economics: multi-currency (`USD`, `AED`, `RUB`) commission & revenue split simulator with market presets and B2B tech upsell margins.
8. **`i18n.js`** — Client-side dual-language engine with persistent language toggle, URL parameter sync (`?lang=ru|en`), and automatic link decoration.
9. **`hub.css`** — Shared responsive styling, CSS variables, and print stylesheets.

## Security & Compliance Audit

* **No secrets or tokens in code or history:** Clean repository scanned for PATs, API keys, and credentials.
* **Tabnabbing Protection:** All external links (`target="_blank"`) enforced with `rel="noopener noreferrer"`.
* **Zero External Script Dependencies:** No untrusted third-party trackers or CDNs; all core JavaScript runs locally without external execution vectors.
* **Safe DOM Injection:** Dynamic translation insertion strictly controlled through predefined dictionary keys.
